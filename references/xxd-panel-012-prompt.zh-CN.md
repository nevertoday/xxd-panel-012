# XXD Panel 012｜生命色几何线场生产提示词

## 运行时完整画布契约（最高优先级）

- `TOP_BOTTOM` 与 `LEFT_RIGHT` 默认把当前原图作为高保真编辑／参考输入，用本提示词一次生成一张完整成品；不要预先拆成摄影半幅和设计半幅。
- 上下模式在整张成品中保留上方约 50% 的高保真原图，在下方完成本风格转译；左右模式对应左侧约 50% 原图与右侧风格转译。两区要在色彩、光线、节奏、文字与含义上形成一体化设计。
- `DESIGN_ONLY` 与 `WALLPAPER_PACK` 使用完整画布，原图只作身份与内容依据而不显示。壁纸仍按设备分别重新构图。
- `FINAL CANVAS` 指整张最终成品比例／像素，必须由用户在生成前明确；不得静默采用源图尺寸。`DESIGN FRAME` 只在完整画布重试失败并触发确定性拼合兜底时使用。
- 完整画布失败时只针对失败条件重试一次；仍失败、用户要求原片逐像素不变、当前通道无法实现目标画幅，或需要无创像素校准时，才允许脚本拼合。

### 模型优先级与凭据

- **优先使用 GPT Image 2。** 当 GPT Image 2 通过当前内置图像工具或已配置兼容通道可用时，先用它完成本提示词要求的高保真垫图／编辑与完整画布生成。
- 也支持 Seedance 5.0 Pro、Nano Banana Pro（Gemini Image Pro）、Nano Banana 2（Gemini Image Flash）或其他兼容位图模型，但只有实际通道具备原图保真、整张成品画幅、目标语言文字，以及连贯壁纸所需多图参考能力时才可使用。
- 备用模型只替换生图通道，不得改变本提示词的模式、画幅、原图可见性、文案、语言、壁纸关系或“完整画布优先、拼合仅兜底”的执行逻辑。不能满足硬性条件时不得静默降级。
- 没有合适通道时，请用户启用生图工具或提供 API Key。用户主动提供凭据可以用于当前任务，但不得在回复、日志或提示词中回显、展示、记录或泄露其值；未经明确要求不得长期保存或修改全局路由配置。
- 按实际生图能力判断可用性，不因某个工具、供应商名称或单一环境变量缺失就武断判定全部通道不可用。

只处理当前任务明确提供的这一张源照片。先观察并锁定主体或不可拆分关系的身份、轮廓、姿态、动作、结构、负形、方向与叙事关系；至少保留三个源图专属识别线索。不要借用旧成品、样张或其他输入的主体、色彩、文案和构图。

## 聚合显形

把源图最具识别性的主体重构为具有几何秩序的线性实验海报。主体必须由高密度重复线条、错位描线、短促回环和受控的轻微抖动轨迹聚合显形，而不是由一根完整轮廓线描出来。外缘保持清楚、可辨认，内部保持不稳定、流动、叠压和生命感。

人物保留姿态、朝向、衣着体块与关系距离；动物保留身体节奏和头部方向；植物保留生长走势；建筑保留天际线和关键开口；物件与交通工具保留功能轮廓和负形；景观保留源图专属的地形、地平线或空间关系。线场应直接回应源图的动作、张力、静止、增长、平衡、碰撞、聚集或扩散，不添加通用波纹、任意涂鸦和伪数据图形。

## 密度梯度与几何约束

从主体向外围延续同源线条，但逐渐变得更细、更疏、更轻。中心必须是识别与能量最集中的高密区域，外围必须明显降为低密度；禁止均匀光环、无方向线团和为了“丰富”而填充的放射线。

只使用能解释源图方向、关系、节奏或平衡的水平线、垂直线、斜线、圆、圆弧、切线或隐性网格。让这些理性结构对自由线场进行压制、切分、对齐、测量或配重，但不要把网格画成软件界面、科技 HUD 或伪科学图表。

保持平面印刷层次，以线条密度、粗细、叠压和间距制造深浅。禁止写实明暗、数字渐变、霓虹、电影光效、光滑贝塞尔曲线、统一线框、金属 3D、塑料和投影。

## 单一生命主线色

从源图中选择最有生命力、最有辨识度、最能代表主体精气神的一种颜色作为主线色。不要按面积平均取色，也不要默认选最大色块或固定蓝色。可适度提纯、提亮和校正，使颜色干净、鲜明、现代，但必须能追溯到源图。

使用清洁白色、暖白或极浅的源图相容背景。主线色承担整个活跃线场，黑灰只用于微排版和极少量结构标记；层次来自密度、粗细和叠压，不来自渐变。禁止脏色、灰蒙、刻意做旧、多色争夺、彩虹色、大片填色和数字渐变。

## 文案与字体

服从已锁定的自动文案、用户准确文案或无文字模式，以及目标语言／地区。用户准确文案逐字保留；无文字时不生成任何伪文字。

自动文案从源图可见或有依据的情绪、动作、时间、状态、关系或隐喻中提炼一个极短标题，再按需搭配少量状态词、克制哲思短句、编号、标尺或微型注释。日期、地点、出处、坐标、测量值和事实性编号必须由用户提供或可靠确认；纯构图编号必须显然是索引而不是伪造事实。

文字是压住自由线条躁动的理性编辑结构。沿几何轴线、主体轮廓、密度边界、切线或隐性网格排列，可横排、竖排、旋转、穿插、切断或错位。使用目标文字系统原生的极小字号等价、细字重、适当宽字距与精确对齐；不得把拉丁字母的间距、旋转和小型大写规则强套给中文、日文、韩文或阿拉伯文。

## 模式与验收


硬性验收：至少三个源图识别线索；清楚外缘与流动内部；高密重复线、错位描线、短促回环和受控轻抖聚合主体；同源细线向外稀释并形成中心高密、外围低密；几何结构理性约束自由线场；一种源图生命主线色、清洁浅底与黑灰微排版；大面积留白、唯一焦点和精确编辑感；无随机涂鸦、无方向线团、均匀线框、脏旧复古、固定蓝调、多色混杂、数字渐变、赛博科技、商业模板、卡通、照片残片或伪文字。

若任一硬性条件失败，纠正生成资产，不要用程序绘图、SVG、HTML、Canvas 或后期文字覆盖伪造成品。
