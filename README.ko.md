> 고밀도 응집 · 외곽 희박화 · 기하학적 통제 · 하나의 생명색 · 흑회색 마이크로타입

XXD Panel 012는 Codex와 호환 에이전트를 위한 이미지 생성 Skill입니다. 정체성, 실루엣, 자세와 서사 관계를 보존하고, 고밀도 반복선, 어긋난 윤곽선, 짧은 되돌림, 통제된 미세 떨림으로 주제를 응집해 드러냅니다. 바깥 인식 경계는 또렷하고 내부는 불안정하게 흐릅니다.

같은 계열의 선은 바깥으로 갈수록 가늘고 옅고 성기며, 수평·수직·사선·원호·접선·암시적 그리드가 이성적 질서를 세웁니다. 주선색은 면적 평균이 아니라 주제의 생명력과 기운을 가장 잘 대표하는 원본의 한 색입니다. 흑회색 미세 문자는 축, 윤곽, 밀도 경계에 맞춰 자유 선 필드의 동요를 제어합니다.

## 왜 012이 필요한가요

일반적인 ‘실험 선 포스터’는 무작위 낙서, 방향 없는 선 덩어리, 균일한 와이어프레임 또는 사진과 주제의 연결을 잃은 가짜 사이버 인터페이스로 쉽게 무너집니다.

012은 순서를 뒤집습니다.

```text
정체성／실루엣／자세／관계 고정 → 고밀도 반복, 어긋남, 짧은 되돌림, 미세 떨림으로 주제 응집 → 또렷한 경계와 흐르는 내부 유지 → 같은 계열 선을 외곽으로 희박화 → 원본에 근거한 기하로 자유 선 필드 통제 → 원본에서 생명색 하나 선택 → 흑회색 미세 문자를 기하 구조에 통합
```

무관한 사진으로 바꿔도 인식 경계, 밀도 중심, 선 방향, 기하 골격, 주선색과 문구가 거의 그대로 성립한다면 012가 아닙니다.

## 012의 시각적 원칙

- **원본 정체성:** 최소 세 가지 고유 단서로 실루엣, 자세, 동작, 구조, 여백 형태와 서사 관계를 보존합니다.
- **응집해 드러나는 주제:** 고밀도 반복선, 어긋난 윤곽선, 짧은 되돌림, 통제된 떨림이 한 줄 윤곽 대신 주제를 만듭니다.
- **밀도 기울기:** 중심은 고밀도이며 바깥의 동계 선은 눈에 띄게 가늘고 옅고 성깁니다.
- **기하학적 통제:** 원본에 필요한 축, 사선, 원호, 접선, 암시적 그리드만으로 자유 움직임을 나누고 정렬하며 균형을 잡습니다.
- **하나의 생명색:** 가장 큰 색 면이 아니라 주제의 기운으로 주선색을 고르며, 정제하더라도 원본과의 연결을 유지합니다.
- **깨끗한 밝은 바탕과 하나의 초점:** 넓은 여백과 평면 인쇄 깊이를 유지하고 때, 그라데이션, 발광, 3D를 피합니다.
- **이성적 마이크로타입:** 짧은 제목과 소수의 상태어, 인덱스, 눈금, 주석을 기하, 윤곽, 밀도 경계에 정밀하게 맞춥니다.

## 예시 · 곧 추가됩니다

저장소에는 향후 예시를 위한 [`assets/examples/`](assets/examples/) 폴더가 마련되어 있습니다. 프로젝트 작성자가 확인한 012 완성작만 추가하며, 그전에는 다른 스타일의 게시물이나 이미지를 자리표시자로 쓰지 않습니다.

향후 예시는 012의 적용 범위만 보여 줍니다. 예시의 주제, 은유, 팔레트, 문구, 화면 비율은 생성 참조나 기본값이 되지 않습니다.

## 네 가지 출력, 하나의 생명색 선 필드 논리

네 가지 모드는 하나만 또는 여러 개를 함께 선택할 수 있습니다. `1`, `1+3`, `1、2、4`, `전체`라고 답하면 Skill이 중복을 제거하고 1→4 순서로 실행합니다. 각 모드는 별도 작업 폴더에 독립적으로 출력되며 한 장의 모음 이미지로 합치지 않습니다. `전체`는 원본 한 장당 PNG 7개(일반 모드 각 1개＋배경화면 4개)를 만듭니다. 크기는 모드별로 표시해 같은 답변에서 지정할 수 있고, 지정하지 않은 일반 모드는 원본에 맞춥니다. 문구는 기본적으로 선택한 모드가 공유하며 모드별 지정도 가능합니다.

| 모드 | 크기 규칙 | 결과물 |
| --- | --- | --- |
| `top-bottom` | 원본 적응형 | 위에는 전체 원본, 아래에는 012 생명색 기하 선 필드. 두 패널이 원본 크기를 유지하며 정확히 50/50 |
| `left-right` | 원본 적응형 | 왼쪽에는 전체 원본, 오른쪽에는 012 생명색 기하 선 필드. 두 패널이 원본 크기를 유지하며 정확히 50/50 |
| `design-only` | 원본 적응형 | 원본 사진은 보이지 않고 변환 디자인만 표시. 원본 비율과 크기 유지 |
| `wallpaper-pack` | 기기별 네 가지 크기 | 휴대전화, iPad, 데스크톱, 어린이용 스마트워치 PNG 개별 출력 |

정확한 사용자 픽셀 > 지정 비율 또는 용도 > 일반 모드의 원본 적응형 순서입니다. 원본 `012.md`의 3:4는 초기 창작 캔버스일 뿐 현재 Skill의 숨은 기본값이 아닙니다.

짝을 이루는 모드의 사진은 절제된 색 보정과 필요한 환경 확장만 적용해 사실성을 지킵니다. 디자인 단독과 배경화면은 사진을 근거로 사용하지만 원본을 보여 주지 않습니다.

### 배경화면 세트: 연결형 또는 독립형

배경화면에는 숨은 기본 크기가 없습니다. 일반 프리셋은 휴대전화 `1440×3200`, iPad `2048×2732`, 데스크톱 `3840×2160`, 스마트워치 `1024×1024`이며 기기별 사용자 지정 크기도 가능합니다.

- **연결형 세트(권장):** 먼저 iPad 기준 작품을 생성하고 승인합니다. 나머지 세 기기는 원본 사진＋동일한 기준 작품을 참조해 각 화면에 맞게 새로 구성합니다.
- **독립형 네 작품:** 각 기기는 원본 사진만 참조하며 밀도 중심, 선 필드 방향, 기하 골격, 생명색의 배치와 문자 관계를 각각 탐색합니다.

연결형은 크롭이 아닙니다. 네 장 모두 따로 생성하고 구성하며 검수하고, iPad→휴대전화→데스크톱→스마트워치 순으로 참조를 이어 붙이지 않습니다.

## 문구는 자유 선 필드를 제어하는 이성적 구조입니다

생성 전에 자동 문구, 사용자 지정 문구, 무문자 출력 중 하나를 선택합니다. 문구가 있으면 대상 언어나 지역도 지정합니다.

자동 문구는 사진에서 보이거나 근거가 있는 감정, 동작, 시간, 상태, 관계 또는 은유에서 극히 짧은 제목을 만듭니다. 절제되고 날카로우며 생동하는 어조를 쓰되 전기를 꾸며 내거나 의미를 강요하지 않습니다.

필요한 상태어, 미세 주석, 구성 인덱스, 눈금 또는 절제된 철학 문장만 더합니다. 날짜, 장소, 출처, 좌표, 측정값과 사실 번호는 사용자 제공이나 신뢰할 수 있는 근거가 있어야 하며, 구성 인덱스는 조작된 사실로 보이지 않아야 합니다.

사용자가 완성 문구를 주면 그대로 유지합니다. 방향이나 수정 가능한 초안일 때만 대상 독자, 목적, 필수 단어, 어조, 함의를 보존하며 다듬습니다.

언어는 명령문의 언어가 아니라 의도한 독자를 따릅니다.

```text
목표 시장 또는 독자 > 지정한 결과물 언어 > 방향 지시 언어; 모두 불분명하면 생성 전에 질문
```

일본판은 자연스러운 현대 일본어를, 한국 독자용은 자연스러운 현대 한국어와 정확한 띄어쓰기를, 영국판은 영국 영어를 사용합니다. 아랍어판은 기본적으로 자연스러운 현대 표준 아랍어와 올바른 오른쪽에서 왼쪽으로 흐르는 구성을 사용합니다. 외모, 옷, 풍경, 간판으로 국적을 추측하지 않으며 가짜 외국어 문자를 쓰지 않습니다.

## 정확한 기하는 코드가, 작품은 이미지 생성이 맡습니다

이미지 모델이 원본에 묶인 응집 주제, 고밀도 반복선, 어긋남과 되돌림, 외곽 희박화, 기하학적 통제, 하나의 생명색과 흑회색 미세 문자를 만듭니다. `scripts/compose_panel.py`는 캔버스 계획, 정확한 50/50 래스터 합성, 최종 크기와 검수만 수행하며 프로그램 그림으로 결과물을 위조하지 않습니다.

```bash
python3 scripts/compose_panel.py --plan --layout top-bottom --source photo.png
python3 scripts/compose_panel.py --plan --layout left-right --size 2560x1440
python3 scripts/compose_panel.py --audit result.png --layout design-only --size 2048x2048
```

정확한 상하 캔버스는 전체 높이, 좌우 캔버스는 전체 너비가 짝수여야 합니다. 요청 픽셀을 몰래 변경하지 않습니다.

## 경계와 신뢰

- 각 사진은 독립된 작업 안에서만 사용하며 다른 입력, 과거 결과, 예시의 피사체, 색, 문구, 구도를 빌리지 않습니다.
- 호출할 때마다 새 작업 폴더를 만들고 원본과 조건이 같아도 새로 생성합니다.
- 결과물은 PNG 비트맵이며 SVG, HTML, Canvas, 프로그램 드로잉 대체물이 아닙니다.
- 설정된 비트맵 브리지는 정제된 상태만 출력하며 공급자, 엔드포인트, 헤더, 인증 정보, 프롬프트, 응답 본문을 노출하지 않습니다.
- 선택한 일반 모드마다 파일 1개를 반환하고, `wallpaper-pack`을 선택하면 독립 배경화면 4개를 추가합니다. `전체`는 원본 한 장당 PNG 7개를 네 개의 동급 모드 폴더에 저장하며 모음 이미지로 합치지 않습니다.

로컬 합성에는 Python 3와 Pillow가 필요합니다. 안전한 비트맵 브리지는 Python 3.11 이상의 `tomllib`을 사용합니다. 이미지 생성에는 내장 래스터 기능이 있는 호스트 에이전트 또는 이미 설정된 호환 경로가 필요합니다.
